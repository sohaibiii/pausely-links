Pauselyのしくみ

Pauselyは、一日を食べてしまうAppとあなたのあいだに小さな段差を置きます。

あまり使いたくないAppを、あなたが選びます。そのあとは、タップしてもすぐには開きません——Pauselyがまず前に立ち、短い一呼吸を挟みます。深呼吸か、入力する一文か、いま開こうとしている理由への問いかけです。それでも入りたければ、時間を区切って入れます。その時間が終われば、一呼吸がまた戻ってきます。

目的は締め出すことではありません。親指まかせの自動的な習慣を、あなたが本当に下す判断に変えることです。考える10秒があれば、たいていの人はAppを閉じます——そしてPauselyは、それを成果として数えます。

  • 保護スイッチひとつ。オンのあいだ、選んだAppは開くかわりにPauselyの静かなブロック画面を表示します。
  • 3つの一呼吸深呼吸、入力の課題、または意図を書くこと。セットアップがあなたに合うものを選びますが、いつでも変えられます。
  • ルール特定のAppを特定の時間帯に守ります——就寝前、仕事の時間——それぞれに専用の一呼吸と専用の時間を持たせて。ルールは、時間が終わるまで完全にブロックすることもできます。
  • 厳格モード1時間、1日、または選んだ時刻まで、自分との約束を守ります。動いているあいだは保護をオフにできず、ルールも削除できません——あなた自身にも。
  • 代わりの選択肢と日記健やかな代わりの選択肢を最大3つまで、第三の出口として一呼吸の画面に出せます。スクロールするより書きたいときのための日記もあります。
  • 記録守れた一呼吸、取り戻した時間、連続記録、週ごとのグラフ——さらにホーム画面のウィジェットと、アクセス時間が開いているあいだのロック画面のカウントダウン。
  • AIリフレクション（使いたければ）あなたがオンにするまではオフです。「なぜこれを開くのですか？」を短いやりとりに変え、一週間についての短い文章も書きます。Pauselyでネットワークを使う唯一の部分です——プライバシーをご覧ください。

動作条件

デバイスiOS 17またはiPadOS 17以降のiPhoneまたはiPad。ひとつのアプリ、ひとつのレイアウトで、どちらの端末にも。
許可スクリーンタイムへのアクセス。セットアップ中に一度だけ、Apple自身の確認画面で許可します。PauselyはAppleのスクリーンタイムのフレームワーク——iOSに内蔵されたApp使用時間制限と同じしくみ——を使っており、Appを実際にブロックしているのはPauselyではなくAppleです。
アカウント不要です。アプリのどこにも、登録もメールアドレスの入力欄もパスワードもありません。
インターネット不要です。一呼吸も、ルールも、グラフも、日記もオフラインで動きます。ネットワークを使うのは2つだけ。Premiumを購入・復元するときのApple自身の通信と、AIリフレクション——こちらはあなたがオンにするまでオフです。
通知任意で、端末のなかだけで完結します。ブロック画面から一呼吸へ受け渡すため、そしてそのあと「どんな気分で終わったか」を尋ねるために使います。プッシュ通知のサーバーはありません。
言語英語、ドイツ語、スペイン語、フランス語、日本語、韓国語、ブラジルポルトガル語、簡体字中国語。Pauselyは端末の言語に従いますが、設定 → 言語で別の言語を選ぶこともできます。

はじめかた

セットアップは7画面、3分もかかりません。終わるころには保護はもうオンで、最初のルールも書けています。

  1. 一日のどれくらいをスマホに渡しているかを答えます——測定値ではなく、あなた自身の見積もりです。
  2. Appleが尋ねたらスクリーンタイムへのアクセスを許可します。これがないとPauselyは動けません。設定 → スクリーンタイムでいつでも取り消せます。
  3. AppleのピッカーでAppを選びます。Pauselyがその名前を知ることはありません——プライバシーをご覧ください。
  4. 3つの質問に答えます。あなたに合う一呼吸が決まります。
  5. 代わりの選択肢を3つまで加えます——散歩、本、一杯の水、または別のAppへのリンク付きの自分だけの選択肢。
  6. 完了です。選んだAppを開いて、一呼吸に出会ってください。

よくある質問

Pauselyは無料ですか？
はい。無料版はお試しではなく、ちゃんと使える製品です。ルールひとつ、深呼吸の一呼吸、そして記録画面のすべて——一呼吸、成果、取り戻した時間、連続記録、グラフ。
Premiumで何が増えますか？
いくつでも作れるルール、残り2つの一呼吸（入力して進む、意図を書く）、厳格モード、そのアプリを使ったあとの気分と、やめたあとの気分を比べる気分の分析、そして任意のAIリフレクションと週ごとのまとめです。Premiumは月額または年額のサブスクリプション——年額は無料トライアルから始まります——か、一度きりの買い切りです。価格はアプリ内とお住まいの国のApp Storeに表示され、請求はAppleが扱います。
サブスクリプションが切れたらどうなりますか？
あなたが築いたものは何ひとつ取り上げられません。すべてのルールは動き続け、編集もできますし、選んだ一呼吸もAppの前に立ち続けます。閉じるのは「これ以上増やすこと」だけです。カードの期限が切れたからといってスマホを守るのをやめるアプリは、まさに「やめないで」と頼まれたその瞬間にあなたを裏切ることになります。
新しい端末で購入を復元できますか？
はい。Premiumの画面を開いて購入を復元をタップしてください。PremiumはあなたのApple IDに属していて、端末に属しているのではありません。
どのAppをブロックしたか、なぜPauselyは教えてくれないのですか？
本当に知らないからです。Appleのスクリーンタイムは、あなたの端末の外では意味を持たない不透明なトークンをPauselyに渡します——App名も、識別子もありません。PauselyはiOSにブロックを頼めますが、読むことはできません。
保護をオフにできません。故障ですか？
厳格モードが動いていないか確かめてください——ホーム画面に表示されます。動いているあいだは保護をオフにできず、ルールも削除できません。そういう設計です。あなたが選んだ時刻に、ひとりでに終わります。
Pauselyは他のAppでの行動を見ていますか？
いいえ。閲覧内容もメッセージも、どのApp内での活動も、けっして見ていません。記録するのは自分自身の出来事だけ——一呼吸が表示されたこと、そしてあなたが何を選んだか——で、それも端末のなかに残ります。
AIリフレクションとは何ですか。オンになっていますか？
オフです。あなたがオンにするまでは。オンにすると、ひとつの一呼吸が短いやりとりになります。なぜそのAppを開くのかを入力すると、問いが返ってきます。一週間についての短い文章も書きます。その言葉はPausely自身のサーバーへ、そしてモデルを動かしているGoogleへ送られます——日記も、気分の記録も、選んだAppも、けっして送られません。設定 → AIリフレクション → 送られるものにすべての項目が並んでいます。オフに戻せば、アプリはネットワーク通信を一切しなくなります。
iPadでは動きますか？Macでは？
iPadは動きます。PauselyはiPhoneとiPadのためのひとつのアプリで、レイアウトも同じ、Split View、Slide Over、Stage Managerでも動きます。Macは対応していません。Pauselyが土台にしているスクリーンタイムのフレームワークが、そこには存在しないためです。
自分の言語で読めますか？
Pauselyは8つの言語を話し、端末の設定に従います。ほかの言語で読みたいときは——端末のほかの設定を変えずに——設定 → 言語を開いてください。ブロック画面もウィジェットもロック画面も、同じ選択に従います。
すべて消すにはどうしますか？
設定 → あなたのデータ → すべてのデータをリセット。一呼吸も、成果も、ルールも、日記も、気分の記録もすべて空にし、ブロックを解いて、はじめの状態に戻します。厳格モードが動いているあいだは実行できません。詳しくはあなたのデータのページへ。

うまくいかないとき

一呼吸なしでAppが開いてしまう

  • ホーム画面の保護スイッチを確かめてください。
  • スクリーンタイムへのアクセスがまだ有効か確かめてください：設定 → スクリーンタイム → スクリーンタイムにアクセスできるApp。取り消されていた場合、Pauselyは再度お願いするためのボタンが付いた復旧画面を表示します。
  • そのAppがルールにしか入っていない場合、一呼吸はそのルールの時間帯にだけ現れます。
  • さきほど開いたアクセス時間がまだ続いているかもしれません——ロック画面のカウントダウンに残り時間が出ています。

ブロック画面は出るのに、一呼吸が開かない

  • ブロック画面のボタンをタップすると、通知を通じてアプリへ受け渡されます。Pauselyの通知がオフだと、iOSはその受け渡しを届けられません——設定 → 通知 → Pauselyでオンにしてください。
  • Pauselyを直接開いても、待っている一呼吸が開きます。

ウィジェットが古いまま

iOSは独自のタイミングでウィジェットを更新します。Pauselyを開けば、すぐに最新になります。

アプリの言語が違う

設定 → 言語を開いて、使いたい言語を選んでください。Pauselyが描くものはすぐに従います。AppleのApp選択画面はPauselyではなくiOSが描いているため、次回の起動から切り替わります。

Premiumが認識されない

Premiumの画面で購入を復元をタップし、購入したときと同じApple IDで端末にサインインしているか確かめてください。返金や請求のご質問はAppleサポートを通じてAppleが扱います。
